# Handoff: Vince Alvarez Portfolio

Repository: https://github.com/hgtproductions1-sys/vince-alvarez-portfolio (private)

Production website: https://vince-alvarez-portfolio.vercel.app/

## Start here

1. Clone the repository after the owner grants your GitHub account access.
2. Use Node.js 24.20 or later.
3. Run `npm ci`, then `npm run dev` for local work.
4. Review `AGENTS.md`, `README.md`, `DESIGN.md`, `ASSETS.md`, and `DEPLOYMENT.md`.

## What is included

The current website source, six standalone concept sites, local publication assets, project stories, build configuration, and existing checks are included. `npm run build` creates the production site in `dist/`.

The project was already built and deployed to the existing Vercel URL before this GitHub handoff. This repository transfer does not change that deployment or connect GitHub deployment automation.

## Excluded

Dependencies, build output, local QA fixtures, review screenshots and reports, generated ZIP archives, prompt/original-media workspace, and separate Remotion/HyperFrames authoring projects are excluded. The published introduction video and website media required at runtime are retained under `public/`.

## Privacy and publishing

This repository is private because the site includes Vince's portrait and contact details. The owner must invite the receiving GitHub account before it can be cloned. No credentials or deployment tokens are stored here. Ask the owner before changing production hosting or connecting automatic deployments.

The CMS is an optional service described by the portfolio; no CMS editor, authentication, or backend is part of this repository.
